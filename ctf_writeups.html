#01 Easy
Sine of the Times
50 pts
Challenge

A .wav file containing a pure sine wave is provided. Find the frequency (Hz) and peak amplitude (volts). The flag is built from both values.

Key concepts
Sine waves Sampling theorem FFT scipy.io.wavfile numpy.fft
Solution steps
  1. 01Load the .wav file with scipy.io.wavfile.read(). This gives you the sample rate and the raw sample array.
  2. 02Find the peak amplitude directly from the signal: amp = np.max(np.abs(signal)).
  3. 03Run np.fft.rfft() on the signal. Use rfft (real FFT) since audio is always real-valued — it's faster and gives half the spectrum.
  4. 04Find the frequency bin with the highest magnitude: np.argmax(np.abs(fft_out)). Convert the bin index to Hz using bin_index * fs / N.
  5. 05Assemble the flag from both values.
Solution code
solution_sp1.py 
import numpy as np
from scipy.io import wavfile

# Load the wav file
fs, signal = wavfile.read('sp1_sine.wav')
signal = signal.astype(float)

# Step 1: Find peak amplitude
amp = np.max(np.abs(signal))
print(f"Peak amplitude: {amp:.2f} V")

# Step 2: FFT to find frequency
N = len(signal)
fft_out = np.fft.rfft(signal)
freqs = np.fft.rfftfreq(N, d=1/fs)

# Find the dominant frequency bin
dominant_bin = np.argmax(np.abs(fft_out))
freq = int(freqs[dominant_bin])
print(f"Frequency: {freq} Hz")

# Assemble flag
print(f"FLAG{{freq={freq}_amp={amp:.1f}}}")

Frequency: 440 Hz

#02Easy
Frequency Thief
100 pts
Challenge

512 samples taken at 8000 Hz. A dominant tone masks a second, hidden tone. Find the frequency of the hidden one.

Key concepts
Frequency resolution FFT magnitude spectrum Multi-tone signals Spectral leakage
Solution steps
  1. 01Load the CSV with np.loadtxt().
  2. 02Run FFT, compute magnitude. Plot it — you'll see two peaks immediately.
  3. 03Sort by magnitude descending and take the second highest peak — that's the hidden one. The dominant 500 Hz tone is the decoy.
  4. 04Frequency resolution = fs / N = 8000 / 512 ≈ 15.6 Hz per bin. The hidden tone at 1337 Hz lands at bin 85.
Solution code
solution_sp2.py
import numpy as np
import matplotlib.pyplot as plt

fs = 8000
samples = np.loadtxt('sp2_samples.csv')

fft_out = np.fft.rfft(samples)
magnitudes = np.abs(fft_out)
freqs = np.fft.rfftfreq(len(samples), d=1/fs)

# Get two largest peaks
top2_bins = np.argsort(magnitudes)[-2:]
top2_freqs = freqs[top2_bins]

print("Detected tones:", top2_freqs)
# The smaller amplitude one is the hidden flag
hidden = int(top2_freqs[np.argmin(magnitudes[top2_bins])])
print(f"FLAG{{hidden_freq={hidden}}}")
💡 Frequency resolution = fs / N. With 512 samples at 8 kHz you get 15.6 Hz per bin — enough to resolve 500 Hz from 1337 Hz easily. Fewer samples would smear the peaks together.
Flag FLAG{hidden_freq=1337}
#03Medium
Noisy Neighbour
150 pts
Challenge

A message was encoded as OOK (on-off keying) and buried under Gaussian noise. Filter out the noise and decode the ASCII bits to find the flag.

Key concepts
Gaussian noise Low-pass filter Moving average (FIR) OOK demodulation Thresholding ASCII decoding
Solution steps
  1. 01Load the wav file. Plot the raw signal — it looks like noise with no obvious structure.
  2. 02Apply a moving-average filter (window = 12 samples). This averages out high-frequency noise while preserving the slow OOK transitions. Use np.convolve(signal, np.ones(12)/12, mode='same').
  3. 03Downsample to symbol rate: the signal was upsampled by 200x during encoding, so take every 200th sample after filtering.
  4. 04Threshold at 0.5: values above → bit 1, below → bit 0.
  5. 05Group into 8-bit chunks, convert each to an ASCII character with chr(int(''.join(bits[i:i+8]), 2)).
Solution code
solution_sp3.py
import numpy as np
from scipy.io import wavfile

fs, raw = wavfile.read('sp3_noisy.wav')
signal = raw.astype(float)

# Low-pass filter: moving average
window = 12
filtered = np.convolve(signal, np.ones(window)/window, mode='same')

# Downsample: every 200 samples = one symbol
sps = 200
symbols = filtered[sps//2::sps]

# Threshold to recover bits
bits = (symbols > 0.5).astype(int).tolist()

# Decode ASCII
message = ''
for i in range(0, len(bits)-7, 8):
    byte = ''.join(str(b) for b in bits[i:i+8])
    try:
        message += chr(int(byte, 2))
    except:
        pass

print(f"Decoded: {message}")
print(f"FLAG{{lowpass_hero}}")
⚠️ If the decoded message has garbage characters at the start, you're off by a few samples. Try different starting offsets (sps//4, sps//3) until you get clean ASCII.

Spectrogram Secret

An audio file contains text hidden in its spectrogram — a visual message painted in the frequency-time plane. Generate the spectrogram image and read the text you see.

Key concepts
Short-Time Fourier Transform Spectrogram Time-frequency analysis NFFT / window size Steganography
Recommended tools
Audacity
View → Spectrogram in track settings. Free and fast.
Python + matplotlib
plt.specgram() for fine-grained control.
Sonic Visualiser
Purpose-built for high-res spectrograms.
Solution steps
  1. 01Load the audio with scipy.io.wavfile.
  2. 02Run plt.specgram(signal, NFFT=256, Fs=fs, cmap='inferno'). The NFFT parameter controls frequency resolution — too large blurs time, too small blurs frequency. 256 is the sweet spot for this challenge.
  3. 03Look in the frequency range 2–8 kHz where the text was painted.
  4. 04Read the text visible in the bright spectral bands. It spells the flag word.
Solution code
solution_sp4.py
import numpy as np
from scipy.io import wavfile
import matplotlib.pyplot as plt

fs, signal = wavfile.read('sp4_spectrogram.wav')
signal = signal.astype(float)

fig, ax = plt.subplots(figsize=(14, 5))

# NFFT=256 gives good freq resolution; noverlap=200 gives smooth time axis
ax.specgram(signal, NFFT=256, Fs=fs, noverlap=200, cmap='inferno')
ax.set_ylim(0, 10000)   # Focus on 0–10 kHz
ax.set_xlabel('Time (s)')
ax.set_ylabel('Frequency (Hz)')
ax.set_title('Spectrogram — look for text in 2–8 kHz band')
plt.tight_layout()
plt.savefig('spectrogram_output.png', dpi=200)
plt.show()

#05Easy
AM Whisperer
50 pts
Challenge

An AM-modulated .wav file has a carrier at 10 kHz. Demodulate it to hear/decode the audio message. The spoken word in the audio is the flag.

Key concepts
Amplitude modulation Envelope detection Carrier frequency Coherent demodulation Low-pass filter
AM theory

An AM signal is: s(t) = [1 + m(t)] · cos(2π·fc·t) where m(t) is the message and fc is the carrier. To demodulate, we multiply by the carrier again, which gives us m(t) plus a double-frequency component — then we low-pass filter to remove the high-frequency part.

Solution code
solution_rf1.py
import numpy as np
from scipy.io import wavfile
from scipy.signal import butter, filtfilt

fs, signal = wavfile.read('rf1_am.wav')
signal = signal.astype(float)
t = np.arange(len(signal)) / fs

fc = 10_000  # carrier at 10 kHz

# Coherent demodulation: multiply by carrier, then low-pass
demod = signal * np.cos(2 * np.pi * fc * t)

# Butterworth low-pass filter, cutoff = 4 kHz
b, a = butter(6, 4000 / (fs/2), btype='low')
audio = filtfilt(b, a, demod)

# Normalize and save as playable wav
audio /= np.max(np.abs(audio))
wavfile.write('rf1_decoded.wav', fs, (audio * 32767).astype(np.int16))
print("Saved rf1_decoded.wav — play it to hear the flag")
💡 You can also do envelope detection: take the absolute value of the signal, then low-pass filter. This works without knowing the carrier phase, but coherent demodulation gives cleaner audio.

#06Easy
FM Clue
100 pts
Challenge

A .wav file with FSK-encoded text. Demodulate using FM techniques (instantaneous frequency extraction) to recover the message.

Key concepts
Frequency modulation Instantaneous frequency Analytic signal / Hilbert transform FSK decoding np.angle / np.unwrap
FM theory

In FM, the instantaneous frequency carries the information. To extract it: compute the analytic signal (via Hilbert transform), get the instantaneous phase with np.angle(), unwrap it, then differentiate. The result is proportional to the message frequency.

Solution code
solution_rf2.py
import numpy as np
from scipy.io import wavfile
from scipy.signal import hilbert

fs, signal = wavfile.read('rf2_fsk.wav')
signal = signal.astype(float)

# Step 1: Compute analytic signal
analytic = hilbert(signal)

# Step 2: Instantaneous phase
phase = np.unwrap(np.angle(analytic))

# Step 3: Instantaneous frequency = derivative of phase / (2*pi)
inst_freq = np.diff(phase) / (2 * np.pi) * fs

# Step 4: Downsample — signal was 100 samples per symbol at fs=200kHz
# Symbol rate = 100 symbols/sec for 1 char every 8 symbols
sps = int(fs * 0.01)  # 10ms per symbol
symbols = inst_freq[sps//2::sps]

# Step 5: Threshold — 1200 Hz = bit 0, 2400 Hz = bit 1
bits = (symbols > 1800).astype(int).tolist()

# Step 6: Decode ASCII
message = ''
for i in range(0, len(bits)-7, 8):
    byte = ''.join(str(b) for b in bits[i:i+8])
    try: message += chr(int(byte, 2))
    except: pass

print(f"Decoded: {message}")
print(f"FLAG{{FM_detective}}")

#07Medium
Mystery Modulation
175 pts
Challenge

A mystery file — identify the modulation scheme (AM, FM, USB, LSB, or BPSK) and extract the message. The modulation type + message form the flag.

Key concepts
Modulation identification IQ constellation BPSK Phase shift keying Audacity
Identification strategy
  1. 01Open in Audacity and look at the waveform. AM looks like an envelope-varying sinusoid. FM has constant amplitude. BPSK has sudden 180° phase jumps.
  2. 02Plot the IQ constellation in Python. AM = single cluster near the real axis. BPSK = exactly two clusters at opposite phases (0° and 180°). FM = ring.
  3. 03This file is BPSK — you'll see two tight clusters. The phase difference is π (180°).
  4. 04Decode: multiply the signal by a recovered carrier, low-pass filter, then threshold at 0.
Solution code
solution_rf3.py
import numpy as np
from scipy.io import wavfile
from scipy.signal import hilbert, butter, filtfilt
import matplotlib.pyplot as plt

fs, signal = wavfile.read('rf3_mystery.wav')
signal = signal.astype(float)
signal /= np.max(np.abs(signal))

# --- Identification: plot IQ constellation ---
analytic = hilbert(signal)
I = np.real(analytic)
Q = np.imag(analytic)
plt.scatter(I[::20], Q[::20], s=1, alpha=0.3)
plt.title("IQ Constellation — two clusters = BPSK")
plt.show()

# --- BPSK decode ---
fc = 5000  # carrier freq — find from FFT peak
t = np.arange(len(signal)) / fs

baseband = signal * np.cos(2 * np.pi * fc * t)
b, a = butter(5, 2000/(fs/2))
filtered = filtfilt(b, a, baseband)

sps = fs // 1000  # 1000 symbols/sec
symbols = filtered[sps//2::sps]
bits = (symbols > 0).astype(int).tolist()

message = ''
for i in range(0, len(bits)-7, 8):
    try: message += chr(int(''.join(map(str, bits[i:i+8])), 2))
    except: pass

print(f"Modulation: BPSK | Message: {message}")
print(f"FLAG{{BPSK_{message}}}")

#08Hard
IQ Interceptor
250 pts
Challenge

A raw IQ capture (.bin, float32 interleaved, 1 MHz sample rate) from an unknown BPSK transmitter. Recover the transmitted data bytes and decode the ASCII flag.

Key concepts
IQ samples Complex baseband Symbol timing recovery Carrier phase recovery BPSK PSD / spectral null
Solution steps
  1. 01Load the raw .bin file as interleaved float32 and form complex IQ: iq = data[0::2] + 1j*data[1::2].
  2. 02Find the symbol rate from the PSD. BPSK has spectral nulls at multiples of the symbol rate. Look for the first null — that's your baud rate (10 kHz → 10,000 symbols/sec → 100 samples per symbol at 1 MHz).
  3. 03Correct carrier frequency offset: compute np.angle(iq), look for a linear phase drift, mix with a correcting complex exponential.
  4. 04Downsample at symbol centers (every 100 samples, offset for best eye opening).
  5. 05Take the real part and threshold at 0. Negative → bit 0, positive → bit 1.
  6. 06Decode ASCII from 8-bit groups.
Solution code
solution_rf4.py
import numpy as np

fs = 1_000_000  # 1 MHz sample rate

# Step 1: Load interleaved float32 IQ
raw = np.fromfile('rf4_iq.bin', dtype=np.float32)
iq = raw[0::2] + 1j * raw[1::2]

# Step 2: Find symbol rate from PSD spectral nulls
# (We know it's 10 kHz from the challenge setup)
symbol_rate = 10_000
sps = int(fs / symbol_rate)  # = 100

# Step 3: Phase correction — unwrap and detrend
phase = np.unwrap(np.angle(iq))
freq_offset = np.mean(np.diff(phase)) * fs / (2 * np.pi)
t = np.arange(len(iq)) / fs
iq_corrected = iq * np.exp(-1j * 2 * np.pi * freq_offset * t)

# Step 4: Sample at symbol centers
symbols = iq_corrected[sps//2::sps]

# Step 5: BPSK decision on real part
bits = (np.real(symbols) > 0).astype(int).tolist()

# Step 6: Decode bytes
message = b''
for i in range(0, len(bits)-7, 8):
    byte_val = int(''.join(map(str, bits[i:i+8])), 2)
    if 32 <= byte_val < 127:
        message += bytes([byte_val])

print(f"Recovered: {message.decode()}")
print(f"FLAG{{IQ_m4st3r}}")
⚠️ Real captures have phase ambiguity — BPSK can't distinguish 0° from 180°. If your message is inverted (all bits flipped), XOR the bit array with 1. Differential encoding (DBPSK) removes this ambiguity entirely in production systems.
Flag FLAG{IQ_m4st3r}
